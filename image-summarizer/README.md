# Edge AI Image Summarizer

**On-device image region summarization using Qualcomm AI Hub**

Built for the [Edge AI Developer Hackathon](https://www.qualcomm.com/developer/events/edge-ai-developer-hackathon) powered by Qualcomm Technologies.

---

## What It Does

Load any image, draw a movable/resizable **context window** over a region of interest, and get an **AI-generated text summary** of just that region — all running **entirely on-device** with Qualcomm Hexagon NPU acceleration.

## Quick Start

### 1. Install Dependencies

```bash
# Use x64 Python on Snapdragon X Elite (ARM64 Python won't work with qai-hub)
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Linux/Mac

pip install -r requirements.txt
```

### 2. Pre-compute Text Embeddings (one-time setup)

```bash
python scripts/precompute_text_embeddings.py
```

### 3. Run the App

```bash
python main.py                    # CLIP mode (recommended)
python main.py --mode blip        # BLIP captioning mode
python main.py --mode hybrid      # Both models
```

### 4. (Optional) Export Models for NPU Acceleration

```bash
# Requires Qualcomm AI Hub account
pip install qai-hub qai-hub-models
qai-hub configure --api_token YOUR_TOKEN

python scripts/export_clip.py     # Compile CLIP for Snapdragon NPU
python scripts/export_blip.py --compile   # Compile BLIP for NPU
```

## Architecture

```
User loads image → draws context window → crops region
                                              ↓
                         CLIP Image Encoder (NPU, ~25ms)
                                              ↓
                    Cosine similarity with pre-computed text embeddings
                                              ↓
                         Natural language summary displayed
```

## Summarization Modes

| Mode | Speed | Quality | Description |
|------|-------|---------|-------------|
| `clip` | Fast (~25ms on NPU) | Good | Zero-shot: matches image against text descriptions |
| `blip` | Medium (~200ms) | Better | Generates natural language captions |
| `hybrid` | Slower (~250ms) | Best | Combines CLIP labels with BLIP captions |
